# Правила клиентов: общие константы

Некоторые числа поведения клиента Orbitle задаёт дважды: на Swift (`orbitle-ios`) и на Kotlin
(`maxly-shared`, Android и Desktop). Здесь они записаны один раз, чтобы не разошлись. Оба
клиента сверяют свои константы с этим файлом в тестах: Kotlin — `ClientRulesFixtureTest`
(`maxly-shared/src/test`) против `ReadMarkRules`. Значение меняется только здесь и в обоих
клиентах вместе.

## Формат файла

```json
{
  "name": "constants",           // имя файла без .json
  "version": 1,                  // растёт, когда меняется смысл или набор полей
  "description": "...",
  "readMarks": {
    "debounceMs": 200,
    "minVisibleFraction": 0.3
  },
  "notHere": "..."               // для чтения, тесты не смотрят
}
```

## Значения

- **`readMarks.debounceMs`** — отметка прочтения уходит через столько миллисекунд после
  последней смены кандидата. Пока она ждёт, более новый кандидат заменяет прежний: быстрая
  прокрутка шлёт одну отметку, и только самую новую.
- **`readMarks.minVisibleFraction`** — сообщение считается увиденным, когда видна хотя бы такая
  доля его высоты (0.3 — 30 %).

## Что остаётся в клиентах

Эти части зависят от платформы, в файл не входят, но обязательны для обоих клиентов:

1. **Видимая область** — только лента: верхняя панель, поле ввода и экранная клавиатура в неё не
   входят, строки под ними не считаются видимыми.
2. **Отмена.** Ждущая отметка отменяется, когда экран становится неактивным: приложение ушло в
   фон, окно свернули или оно потеряло фокус.
3. **Только вперёд.** Отметка уходит, только если она новее последней отправленной.

## Чего здесь нет

Ряд размеров картинок и выбор размера (первый размер не меньше запрошенного, умноженного на
плотность экрана) живут в ядре `fighxy/max-kmp-core`, не здесь.
