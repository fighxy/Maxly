# Участники группы: общие сценарии

Список «Участники» группы или канала на Swift (`maxly-ios`) и Kotlin (`maxly-shared`).
Swift проигрывает сценарии в `MembersFixtureTests` (`maxly-ios/Tests/MaxlyDomainTests`),
логика — `ChatMembersRules` в `MaxlyDomain`. Новый файл без проигрывателя — ошибка.

## Протокол

`CHAT_MEMBERS` 59 `{chatId, type: "MEMBER", marker, count: 50}`, ответ
`{members: [{contact, presence?}], marker?}`. Поиск на сервере — тот же запрос с `query` без
`marker` и `count`. Ролей в ответе нет: они в карточке чата — `owner` и
`adminParticipants {userId: {permissions, inviterId, alias?}}`.

## Правила

**Листание (`paging`).** Первый запрос — `marker: 0`. Поведение клиента, не ядра: перед первой
страницей экран обновляет карточку чата (`CHAT_INFO`), чтобы роли из `owner` и
`adminParticipants` были свежими. Ядро само запрашивает карточку, только если чата у него нет;
сценарии этого не проверяют. Следующий — с маркером из ответа.
Конец списка, если в ответе:
- нет `marker` или он `null`;
- `marker` равен 0 (это маркер первой страницы — иначе список пошёл бы по кругу);
- тот же `marker`, что спрашивали;
- ни одного нового участника.

Маркер бывает строкой. Повторы id выбрасываются, остаётся первое появление.

**Значки и порядок (`roles`).** Владелец — `owner`, админы — ключи `adminParticipants`
(владелец, который есть и там, — владелец). Порядок: владелец, админы, остальные — каждый в
порядке сервера. Значок: «владелец»; у админа — `alias`, без него (или пустой) «админ»; у
остальных значка нет.

**Поиск (`search`).** Сначала — среди загруженных: подстрока полного имени или имени для
упоминаний (`mentionName`, ник без «@») без учёта регистра, «ё» = «е», пробелы запроса по
краям не важны, пустой запрос — все; запрос с «@» ищет только по `mentionName`, «@» без
текста — все; порядок сохраняется. Только если список загружен не весь, через 200 мс после
последнего изменения запроса спрашивается сервер (`query`). Поиск на сервере не листается:
одна страница, её участники добавляются после локальных без повторов.

## Файлы

`paging`: `pages` — ответы сервера по порядку (`members [{id, name}]`, `marker?`);
`expect.requests` — маркеры отправленных запросов, `expect.ids` — итоговый список.
`roles`: `chat {owner?, adminParticipants?}`, `members`; `expect` — `[{id, badge}]` по порядку.
`search`: `members [{id, name, mentionName?}]`, `query`; `expect` — id по порядку.
