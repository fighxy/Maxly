# Выбор сообщений: удаление, пересылка, копирование — общие сценарии

Режим выбора нескольких сообщений («Выбрать» в меню сообщения) есть на Swift (`maxly-ios`)
и Kotlin (`maxly-shared`). Swift проигрывает сценарии в `SelectionFixtureTests`
(`maxly-ios/Tests/MaxlyDomainTests`), логика — `MessageSelectionRules` в `MaxlyDomain`.
Новый файл без проигрывателя — ошибка.

## Удаление (`delete`)

Один запрос `MSG_DELETE` 66 `{chatId, messageIds: [все выбранные], forMe}`. Для каждого
сообщения — `all` (можно у всех), `self` (только у себя) или `none` (нельзя):

| Чат | Правило |
|---|---|
| «Избранное» (id `0`) | `self` (выбора нет; Orbitle стирает сообщение на сервере целиком) |
| Неотправленное (`sending`, `failed`) | `self` (стирается на устройстве; в канале без прав — `none`) |
| Личный чат | своё моложе `editTimeout` — `all`, иначе `self` |
| Группа | админ — `all`; своё моложе `editTimeout` — `all`; иначе `self` |
| Канал | админ — `all` (и только у всех), остальные — `none` |

`editTimeout` — `edit-timeout` конфига сервера в секундах. Нет поля — **0**, как в веб-клиенте:
своё у всех не удалить. «Моложе» — строго: `now - time < editTimeout`.

Подтверждение:
- `canDelete` — ни одного `none` (и выбор не пуст);
- `showsForEveryone` — переключатель «Удалить у всех»: все `all` и это не канал;
- `forEveryoneByDefault` — его начальное положение: включён, когда показан;
- `forcesForEveryone` — канал с правами: удаляется только у всех, без переключателя.

Любое выбранное сообщение, которое у всех удалить нельзя, оставляет только «у себя».

## Пересылка (`forward`)

Один `MSG_SEND` 64 с `link: {type: FORWARD, chatId, messageId}` **на сообщение на чат**.
Сначала комментарий (если не пустой после обрезки) в каждый чат, затем сообщения от старых к
новым (равное время — по id как числу), каждое — во все выбранные чаты по порядку выбора.
Повторы сообщений и чатов выбрасываются.

## Копирование (`copy`)

Наш формат (у веб-клиента копирования нескольких нет):
- одно сообщение — просто его текст (обрезанный);
- несколько — от старых к новым блоки `Имя, [дд.мм.гггг чч:мм]` и текст с новой строки,
  между блоками пустая строка;
- сообщение без текста — подпись вложения, как в списке чатов: `PHOTO` «Фото», `VIDEO`
  «Видео», `VIDEO_MESSAGE` «Видеосообщение», `VOICE` «Голосовое сообщение», `FILE` «Файл»,
  `STICKER` «Стикер», `CONTACT` «Контакт», `POLL` «Опрос»; без вложения — «Сообщение»;
- без имени автора — «Участник»;
- время — в поясе `timeZone` сценария (у приложения — пояс устройства).

## Файлы

Время — мс. `delete`: `me`, `now`, `chat {id, type: DIALOG|CHAT|CHANNEL, admin}`,
`editTimeout?`, `messages [{id, author, time, state: sent|sending|failed}]`.
`forward`: `messages [{id, time}]`, `targets`, `comment`; `expect.requests` —
`{target, comment}` или `{target, messageId}` по порядку. `copy`: `timeZone`,
`messages [{id, time, authorName, text, media?}]`, `expect` — строка буфера.
