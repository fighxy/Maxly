# Статус «в сети / был(а)»: общие сценарии

Строку статуса человека (контакты, профиль, шапка личного чата) Orbitle собирает дважды: на
Swift (`maxly-ios`) и на Kotlin (`maxly-shared`, Android и Desktop). Эти файлы — общие
сценарии, чтобы тексты не разошлись.

Swift проигрывает их в `PresenceFixtureTests` (`maxly-ios/Tests/OrbitlePresentationTests`):
статус из полей протокола (`Contact.Presence.server(status:seenMs:)`), строка
`ContactsFormatter.status` и шапка `ChatHeaderStatus.make`. Kotlin-проигрыватель пишется
отдельно и должен гонять все файлы каталога: новый файл без проигрывателя — ошибка теста.

## Откуда данные

`presence = {seen, status}` приходит в ответе `LOGIN` (карта `presence` по id), в
`CONTACT_PRESENCE` 35, у участников `CHAT_MEMBERS` и пушем `NOTIF_PRESENCE` 132 `{userId,
presence}`. `seen` в протоколе — секунды Unix, в сценариях уже миллисекунды (`seenMs`), как
отдаёт мост ядра.

## Формат файла

```json
{
  "name": "relative",              // имя файла без .json
  "description": "...",
  "timeZone": "Europe/Moscow",     // календарь для «сегодня», «вчера», часов и минут
  "nowMs": 1790683200000,          // «сейчас», мс Unix (29 сентября 2026, 15:00 МСК)
  "nowLocal": "2026-09-29 15:00:00 MSK",
  "cases": [
    {
      "id": "5-minutes",
      "status": 0,                 // -1 не прислан, 0 не в сети, 1 в сети, 2 недавно, 3 давно
      "seenMs": 1790682900000,     // 0 — времени нет
      "seenLocal": "...",          // для чтения, проигрыватель не смотрит
      "text": "Был(а) 5 минут назад",  // строка контакта и профиля; "" — строки нет
      "header": "был(а) 5 минут назад", // шапка личного чата; "" — строки нет
      "note": "..."                // необязательно
    }
  ]
}
```

## Правила

1. **Статус.** `1` → «В сети». `2` → «Был(а) недавно» (время скрыто приватностью, `seen` не
   смотрится). `3` → «Был(а) давно». `0` и `-1` → по `seen`; без `seen` статус неизвестен.
   Другой код — «недавно», как у веб-клиента Max.
2. **Неизвестно — пусто.** Ни «недавно», ни «давно»: строки статуса нет (`text` и `header`
   пустые). Раньше iOS показывал «Был(а) недавно», и так выглядели почти все.
3. **Будущее — «только что».** `seen` позже `now` (часы устройства отстают) и меньше 60 секунд
   назад → «Был(а) только что».
4. **Меньше часа** → «Был(а) N минут назад», минуты округляются вниз, склонение:
   1, 21, 31… — «минуту»; 2–4, 22–24… — «минуты»; 0, 5–20, 25–30… и 11–14 — «минут».
5. **Час и больше, сегодня** → «Был(а) в ЧЧ:ММ» (24 часа, ведущий ноль). Формы «N ч назад» в
   iOS нет.
6. **Вчера** (по календарю `timeZone`) → «Был(а) вчера в ЧЧ:ММ».
7. **Раньше, этот год** → «Был(а) Д мес» без времени, месяц — `янв фев мар апр мая июн июл авг
   сен окт ноя дек` (май в родительном, остальные сокращены).
8. **Прошлые годы** → «Был(а) ДД.ММ.ГГГГ».
9. **Шапка чата**: «в сети» со строчной (цветом акцента), остальное — та же строка со строчной
   первой буквой («был(а) вчера в 09:05»). Пустая строка — шапка без статуса.
10. Форма «Был(а)» одна для всех: пол собеседника протокол не сообщает.
11. **Обновление.** Строка пересчитывается со временем: шапка и профиль раз в минуту
    (`TimelineView(.everyMinute)`), список контактов — таймером раз в минуту.

## Строки iOS дословно

| Случай | Контакты и профиль | Шапка чата |
|---|---|---|
| в сети | `В сети` | `в сети` |
| неизвестно | (нет строки) | (нет строки) |
| статус 2 | `Был(а) недавно` | `был(а) недавно` |
| статус 3 | `Был(а) давно` | `был(а) давно` |
| < 1 мин, будущее | `Был(а) только что` | `был(а) только что` |
| < 1 ч | `Был(а) N минуту/минуты/минут назад` | со строчной |
| сегодня | `Был(а) в 12:40` | `был(а) в 12:40` |
| вчера | `Был(а) вчера в 09:05` | `был(а) вчера в 09:05` |
| этот год | `Был(а) 9 сен`, `Был(а) 9 мая` | со строчной |
| прошлые годы | `Был(а) 31.12.2025` | со строчной |

В домене iOS есть ещё `Был(а) на этой неделе` и `Был(а) в этом месяце`, но коды статуса
протокола в них не переводятся, и в сценариях их нет.
