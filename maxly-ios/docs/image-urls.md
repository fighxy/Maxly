# Адреса картинок

Лестницу размеров знает ядро (`IosImageSize`). Приложение передаёт сторону в пикселях: размер в точках, умноженный на масштаб экрана.

- Аватар — форма `square`.
- Миниатюра фото в ленте — форма `width`.
- Полноэкранный просмотр и файл на диске остаются без `fn`.

Просроченный адрес (`expires` в запросе, миллисекунды) обновляется кодом 203, когда сервер включил `photo-url-refresh`. Пачка не больше лимита сервера (по умолчанию 100), одно и то же фото не ставится в очередь дважды, следующая пачка уходит не раньше чем через секунду. Неудача возвращает пачку в очередь. Новый адрес записывается в сообщение.

Сейчас мост не отдаёт флаг `photo-url-refresh` (на конфиге он по умолчанию выключен), поэтому приложение его не включает и код 203 не вызывает.
