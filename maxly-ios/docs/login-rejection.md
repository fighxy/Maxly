# Отказ входа

Ядро само отвечает на серверный PING и само переподключается. Когда сохранённый вход больше не принимают, фаза ядра становится `tokenRejected`, а `loginRejection()` говорит, почему.

Три причины:

| Причина | Токен | Что делает приложение |
| --- | --- | --- |
| `token` | ядро стирает | экран входа, локальная переписка стирается так же, как при выходе. Повторный `logout` ядру не шлётся: токен уже пуст |
| `blocked` | ядро стирает | то же, другие запасные строки |
| `flood` | остаётся | фаза остаётся «вошли», список чатов показывается без сети, сверху плашка. Ядро само в этот момент не переподключается |

Плашка: «Повторить» снова вызывает `start()` с тем же токеном, «Выйти из аккаунта» — обычный выход. После успешного подключения плашка исчезает.

Заголовок сервера важнее нашего. Если заголовка нет, показываем запасной заголовок и запасной текст, а не обрывок ответа. Если заголовок есть, текст — `localizedMessage`, иначе `description`.

Запасные строки:

- поток: «Слишком много входов» / «Сервер временно ограничил вход. Сохранённые чаты доступны без сети, повторите позже»
- токен: «Сессия завершена» / «Сервер больше не принимает этот вход. Войдите снова по номеру телефона»
- блокировка: «Аккаунт заблокирован» / «Сервер не пускает в этот аккаунт. Войти можно будет, когда блокировку снимут»

Отказ во время ввода кода из SMS шаг кода не сбрасывает. Этот экран по-прежнему говорит «Неверный код», если код не подошёл.
