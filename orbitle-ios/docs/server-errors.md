# Текст ошибки сервера

Колбэк ядра по-прежнему отдаёт `kind` и ключ. Пока он выполняется, `IosErrors.current()` даёт текст: `displayText` — это заголовок, а если заголовка нет, `localizedMessage`. Пустая строка значит, что сервер ничего не прислал (так же у сети и таймаута). Читать его нужно сразу в колбэке, до перехода на другую очередь.

Если текст не пустой, экран показывает его. Иначе остаётся прежняя русская фраза для этого вида ошибки. Повтор отправки при коде сервера не отключается: категория запроса остаётся серверной, когда текст едет рядом с кодом.

Шаги входа этот текст не подменяют. Неверный код из SMS по-прежнему «Неверный код».
