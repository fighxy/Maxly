# Эмодзи и стикеры

Схема запросов взята из KometTeam/Komet (`StickersModule`, `AnimojiModule`, `EmojiPanel`, `StickerPanel`).

## Панель

- **Открытие.** Кнопка 😊 внутри поля ввода открывает панель на месте клавиатуры, той же высоты (`keyboardWillChangeFrame`). На открытой панели эта кнопка становится ⌨️ и возвращает клавиатуру. Нажатие в поле ввода тоже закрывает панель.
- **Устройство.** Сверху полоса разделов: нажатие прокручивает к разделу, текущий раздел подсвечен. Ниже сетка с закреплёнными заголовками. Внизу переключатель «Эмодзи | Стикеры», а в режиме эмодзи ещё кнопка «стереть», которая повторяет удаление, пока её держат.
- **Порядок разделов эмодзи:**
  1. «Недавние» — только если эмодзи уже выбирали; до 24 штук, хранятся на устройстве.
  2. «Анимированные» — анимодзи сервера с Lottie. Это те же анимодзи, что в реакциях.
  3. Обычные категории Unicode: смайлы и люди, животные, еда, активность, путешествия, предметы, символы, флаги.
- **Обычные эмодзи** (`EmojiCatalog+Data.swift`) сгенерированы из `emoji-test.txt` unicode.org. Взяты только полностью квалифицированные эмодзи до Emoji 15.0 (их рисует iOS 17), без вариантов оттенка кожи.
- **Стикеры:**
  - разделы: «Недавние» (свои с устройства, затем недавние с сервера), дальше наборы, свои первыми;
  - стикеры набора загружаются, когда раздел появляется на экране;
  - нажатие отправляет стикер сразу, долгое нажатие показывает его крупно с кнопкой «Отправить».

## Протокол

| Что | Запрос |
|-----|--------|
| Свои наборы | `ASSETS_UPDATE` 27 `{type: FAVORITE_STICKER, sync: 0}` → `FAVORITE_STICKER_SETS.stickerSets` |
| Каталог и недавние | `ASSETS_UPDATE` 27 `{type: STICKER, sync: 0}` → `NEW_STICKER_SETS` (+ `marker`), `RECENTS.recentsList` |
| Следующие страницы | `ASSETS_GET` 26 `{sectionId: NEW_STICKER_SETS, from: marker, count: 100}` |
| Наборы, стикеры | `ASSETS_GET_BY_IDS` 28 `{type: STICKER_SET / STICKER, ids}` пачками по 100 |
| Анимодзи | `ASSETS_UPDATE` `ANIMOJI_SET` → `ASSETS_GET_BY_IDS` `ANIMOJI_SET` → `ANIMOJI` (`lottieUrl`) |
| Отправка стикера | `MSG_SEND` с `attaches: [{_type: STICKER, stickerId}]` |
| Анимодзи в тексте | `elements: [{type: ANIMOJI, from, length, entityId, attributes: {animojiLottieUrl}}]` |

Каталоги кэшируются в `Caches/Stickers` (`CoreStickerRepository`), поэтому панель открывается сразу и без сети. Lottie-файлы лежат в `Caches/Lottie` (`LottieStore`) и рисуются библиотекой airbnb Lottie (`lottie-spm`). Кэши стираются при выходе из аккаунта.

## Сообщения

- **Стикер** рисуется без подложки, 168 pt. Если у стикера есть Lottie, он анимирован, иначе показывается картинка. Время лежит на полупрозрачной плашке. Цитата и имя автора выводятся над стикером.
- **Сообщение из одних эмодзи** (от одного до трёх) выводится крупно без подложки. Если это одно анимодзи с отметкой `ANIMOJI`, вместо символа играет его Lottie.
- **Анимодзи внутри обычного текста** пока выводятся простыми эмодзи.
- **Вставка из панели.** Анимодзи из панели запоминаются в поле ввода (`AnimojiDraft`). При отправке их вхождения в тексте уходят отметками `ANIMOJI` через очередь исходящих (`TextSpan.Kind.animoji` в разметке сообщения).
- **Reduce Motion.** Анимации стоят на первом кадре.
