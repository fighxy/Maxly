# «Печатает…» и другие действия

Кто чем занят в чате: печатает, записывает аудио или видеосообщение, отправляет фото, видео
или файл, выбирает стикер. Значения протокола взяты из официального веб-клиента Max (только
факты, код не заимствован). Общие с Kotlin сценарии и полный формат — в
[`test-fixtures/typing`](../../test-fixtures/typing/README.md).

## Протокол

| Опкод | Тело | Примечания |
|---|---|---|
| 65 `MSG_TYPING` | `{chatId, type}`, в комментариях ещё `postId` | клиент → сервер, ответа нет |
| 129 `NOTIF_TYPING` (пуш) | `{chatId, userId, type}` | пустой и незнакомый `type` — `TEXT` |

`type`: `TEXT`, `AUDIO`, `VIDEO_MSG`, `PHOTO`, `VIDEO`, `FILE`, `STICKER` (`TypingKind`).
Отдельного «перестал печатать» нет.

## Приём

- `SyncEngine` передаёт пуш в `ChatRepositoryImpl.noteTyping(chatId:userId:type:)`, тип мост
  кладёт в поле `text` события `typing`. Свои пуши не учитываются.
- Сроки — `TypingTracker` (OrbitleDomain): отметка живёт 8 с после последнего пуша
  (`typingTTL`, включительно), повторный пуш продлевает срок и меняет тип, место в очереди не
  меняется. Сообщение автора снимает отметку сразу.
- Поток `ChatRepository.typing()` отдаёт `[id чата: [TypingActivity]]` — печатающие по времени
  начала, с типом и именем. Имя берётся из сохранённых сообщений (последнее непустое
  `authorName` этого пользователя в любом чате), в тексте — только первое слово.

## Текст

`TypingFormatter` (OrbitlePresentation) — одна строка для списка чатов (`ChatListFormatter.item`)
и шапки чата (`ChatHeaderStatus.make`):

- личный чат — только действие: «печатает…», «записывает аудио…»;
- группа — тип того, кто начал раньше всех, и только печатающие с этим типом: «Иван печатает…»,
  «Иван и Петя выбирают стикер…», «Иван, Петя и Маша печатают…», «Иван и ещё 3 печатают…»;
- нет нужного имени — счёт: «2 участника печатают…», один без имени — только действие;
- канал — ничего.

Шапка показывает тот же текст без «…»: точки рисует `TypingStatus`. Приватный режим прячет
имена: строка списка берёт `anonymousTyping` («2 участника печатают…»), шапка в приватном
режиме статус не показывает вовсе.

## Отправка

`TypingSendPolicy` — чистые правила с внешними часами, `TypingReporter` — отправляет их кадры
через `TypingSender` и сам делает повторы во время записи:

- один порог на чат для всех типов: не чаще раза в 6 с;
- `TEXT` — на правку текста в поле ввода;
- `AUDIO`, `VIDEO_MSG` — в начале записи и каждые 5 с от её начала, пока она идёт;
- `PHOTO`, `VIDEO`, `FILE` — на ход загрузки вложения;
- `STICKER` — при открытии панели стикеров;
- в чат, куда писать нельзя, ничего не уходит.
- в «Избранное» (`Chat.savedMessagesId`) тоже ничего не уходит: показывать «печатает…» там некому.

Подключение: один `TypingReporter` на приложение (`AppContainer`) с `CoreTypingSender` —
`MaxCore.sendTyping` → мост `sendTyping(chatId:type:)` (вариант без ответа; в комментариях —
с `postId`). Экран чата сообщает о событиях через `ChatViewModel`:

| Событие | Откуда |
|---|---|
| правка текста | `draft` (не правка сообщения и не восстановление черновика, пустой текст не считается) |
| запись голосового или кружка | `RecordingSession.onRecordingChange`: полоса записи появилась / запись отправлена или выброшена |
| ход загрузки | поток `uploadProgress()`: своё сообщение этого чата с фото, видео или файлом |
| панель стикеров | `panelShown` в `ChatView` стал `true` |

`ChatViewModel.typingAllowed` ставит экран по праву на поле ввода (`writable`); пока он `false`,
ничего не уходит. Комментарии к постам «печатаю» пока не шлют.
