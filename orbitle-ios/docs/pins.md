# Закрепы в чате (iOS)

Общее описание — [`docs/pins.md`](../../docs/pins.md) в корне репозитория.

## Откуда берётся плашка

- Закреп из самого чата: служебное сообщение о закреплении в ленте.
- Пуш `pinned` (243): открытый чат сам меняет плашку (`pin`, `unpin`, `unpinAll`), текст
  закрепа берётся из загруженной ленты, иначе «Сообщение».

`GET_PINNED_MESSAGE_STATES` 240 и `PINNED_MESSAGES_GET` 241 iOS не запрашивает: мобильный
сервер их не знает, отвечает «Неизвестный opcode» и рвёт соединение. Поэтому список более
старых закрепов выключен, пока опкод не подтверждён. `MaxAPIClient.pinnedMessages` сразу
возвращает ошибку и в ядро не ходит.

Счётчик «2 из 5», переход к более старому и кнопка списка появляются, только когда в плашке
известно больше одного закрепа (например, пришло несколько пушей). С одним закрепом касание
просто открывает его.

## Закрепить и снять

Только по действию пользователя: `PINNED_MESSAGE_UPDATE` 242 (`pin`, `unpin`, `unpinAll`,
`forMe`, `notify`). Если источнику 242 недоступен, остаётся прежний закреп через
`CHAT_UPDATE` 55.
