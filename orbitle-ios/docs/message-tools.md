# Выбор сообщений, форматирование, участники, контакты, адресная книга, черновики

Шесть функций, которые держатся на вызовах ядра `max-kmp-core` (ревизия в `core.lock`). Общие
с Kotlin сценарии лежат в `test-fixtures/`: `selection`, `formatting`, `members`, `names`,
`drafts`. Формат файлов — `{kind, name, description, cases}`, подробности — в README каждой
папки. Правила из Domain (`MessageMarkup`, `ContactNames`, `DraftSync`, `MessageSelection`,
`ChatMembersRules`) проверяются этими файлами в `SharedFixtureTests`.

## Слои

`MaxIosCore` (мост) → протокол `MaxCore` (`CoreSession.swift`, запасные реализации в
`CoreMessageTools.swift`) → `MaxAPI` / репозитории → протоколы Domain → модели экранов. Если
ядро чего-то не умеет, запасная реализация либо делает старый вызов (правка без разметки,
удаление без отчёта, участники одной страницей), либо бросает `CoreFailure` с ключом
`unsupported`.

## Выбор сообщений

- Пункт «Выбрать» в меню сообщения включает режим. `MessageSelectionModel` хранит выбор,
  считает, что можно сделать, и собирает запросы. Шапка: «Выбрано: N» и «Отмена», внизу
  панель «Копировать / Переслать / Удалить».
- Удаление: лист с переключателем «Удалить у всех». По умолчанию он включён, если это можно
  сделать для всех выбранных. Ядро: `deleteMessages(chatId, messageIds, forEveryone, postId)`
  → `IosDeleteResult(deleted, failed)`. Локально удаляется только то, что сервер удалил, про
  остальное появляется уведомление «Не удалось удалить: N».
- Пересылка: выбор нескольких получателей и комментарий. Пересылает само приложение: сначала
  комментарий, потом сообщения от старых к новым, каждое — отдельный `forwardMessage`.
- Копирование: одно сообщение — просто текст. Несколько — от старых к новым блоки
  «Имя, [дд.мм.гггг чч:мм]» и текст, без текста — подпись вложения.

## Форматирование

- iOS 18+: поле ввода отдаёт выделение, над полем появляется стеклянная панель
  (`ComposerFormatBar`): жирный, курсив, подчёркнутый, зачёркнутый, моноширинный, цитата,
  ссылка и «Обычный текст». Состояние — `ComposerFormat`, смещения — UTF-16.
- Отправка: `sendFormattedText(chatId, text, elementsJson, replyTo)`; правка —
  `editMessage(chatId, messageId, text, elementsJson)` всегда с полным списком элементов,
  `[]` снимает всё оформление. Если в тексте только анимодзи и упоминания, остаётся старый
  путь отправки.

## Участники группы

- Профиль группы → «Все участники и поиск» (`ChatMembersView`, `ChatMembersListModel`).
- Страницы: `loadChatMembers(chatId, marker, count)` → `(members, nextMarker)`, следующая
  страница — при показе последних строк. Поиск: сначала по загруженным, через 0,35 с —
  `searchChatMembers(chatId, query)`, результаты объединяются без повторов.
- Значки «Владелец» и «Админ» из ролей ядра. Касание участника открывает личный чат.

## Контакты: переименование и удаление

- Меню контакта: «Переименовать» (имя обязательно, имя и фамилия до 64 символов,
  `ContactNameRules`) и «Удалить» с подтверждением.
- Ядро: `renameContact(userId, firstName, lastName)`, `removeContact(userId)`. После
  удаления 5 с висит плашка «Отменить»: контакт добавляется заново (`addContactByPhone` →
  `(user, isNew)`) и при необходимости получает прежнее имя.

## Имена из адресной книги

- Только после разрешения на контакты (полного или выборочного, iOS 18). Настройка «Имена из
  адресной книги» — «Безопасность», по умолчанию включена.
- `AddressBookReader` читает номера и имена, `AddressBookNamesSync` передаёт книгу целиком в
  `setAddressBook([IosPhoneContact(phone, firstName, lastName)])`. Номера сырые, нормализует
  ядро, при повторе номера побеждает первое непустое имя. Книга отправляется заново после
  входа, при возвращении приложения и по `CNContactStoreDidChange`. Выключение настройки или
  отзыв разрешения отправляют пустую книгу.
- На сервер не уходит ничего. Выгрузка книги закрыта флагом
  `AddressBookNamesSync.uploadsToServer = false`. Об этом говорит и
  `NSContactsUsageDescription`.

## Черновики

- Пока человек печатает, черновик сохраняется только на устройстве (`ChatRepositoryImpl`).
- `ServerSyncedDraftStore`: при открытии чата берётся более новый из черновиков устройства и
  сервера (`drafts()`, `DraftSync.merge`). При уходе из чата изменённый черновик уходит в
  `saveDraft(chatId, text, elementsJson, replyTo)`, а пустое поле удаляет серверный черновик
  через `discardDraft(chatId, time)`.
- «Избранное» и чаты с нечисловым id остаются локальными. На устройстве у черновика хранится
  только текст.

## Ограничения

- Права админа в группе приложение не знает: удалить чужое сообщение у всех в группе нельзя.
- Срок правки и удаления своих сообщений у всех с сервера не приходит, поэтому не проверяется.
- У черновиков на устройстве нет оформления и ответа, они отправляются только из текста.
- `forwardMessages` ядра пока не используется: пересылка идёт по одному сообщению.
- В CI `ios.yml` реагирует на пути `orbitle-ios/**`. Изменения только в `test-fixtures/` сборку
  не запускают, общие сценарии проверяются вместе со следующей сборкой iOS.
