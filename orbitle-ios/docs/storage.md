# Кэш и «Данные и память»

Постановка Ивана от 01.10.2026: продумать систему кэша, хранить изображения в кэше, в настройках — раздел «Данные и память» для управления кэшем. Образец — экраны использования памяти в популярных мессенджерах.

## 1. Что хранится и где

Всё скачанное лежит в одном корне `Application Support/OrbitleMedia` (`StorageLayout`), по папке на категорию. Корень исключён из резервной копии iCloud (`isExcludedFromBackup`). `Caches` не выбран: система чистит его сама без предупреждения, а экран должен честно показывать, что лежит на устройстве.

| Категория | Папка | Кто пишет | Имя файла |
|---|---|---|---|
| Фото (фото из сообщений и аватары) | `photos/` | `ImagePipeline` (OrbitleUI) | SHA-256 адреса |
| Видео | `videos/` | `MediaRepositoryImpl`, запасной путь просмотра видео | id вложения + расширение |
| Видеосообщения (кружки) | `videoNotes/` | `MediaRepositoryImpl`, перед воспроизведением в ленте | `note<id>.mp4` |
| Голосовые | `voice/` | `MediaRepositoryImpl` при первом воспроизведении | id + `.ogg` (рядом CAF для плеера) |
| Файлы | `files/` | `MediaRepositoryImpl` при открытии файла | id + расширение |
| Прочее | `other/`, файлы прежней раскладки в корне, `Caches/Outgoing`, `tmp`, общий `URLCache` | запись голосовых и кружков, подготовка вложений к отправке | — |

Отдельно от кэша — база SwiftData (`Application Support/Orbitle`): чаты и сообщения для работы без сети. Экран показывает её размер, но вместе с кэшем она не чистится.

Тип вложения определяет категорию: `MediaType.storageCategory`. У кружка свой тип `MediaType.videoNote` (`VideoContent.cacheItem()` при `isRound`).

## 2. Картинки

`ImagePipeline` больше не использует `URLCache`: тот не хранит ответы крупнее 5 % своего объёма, слушается заголовков CDN и не даёт посчитать фото отдельно. Теперь три уровня:

1. **Память** — `NSCache` декодированных картинок, ключ «адрес + размер декодирования», предел 300 штук и 160 МБ. Только её видит `body` экрана.
2. **Диск** — `ImageDiskCache`: исходные байты ответа, файл на адрес. Пишется только то, что читается как картинка: страница ошибки CDN в кэш не попадёт. Читается в фоновой задаче вместе с декодированием (docs/cache-and-motion-review.md), поэтому прокрутка не ждёт диска; после перезапуска фото берутся с диска, без сети.
3. **Сеть** — сессия без `URLCache`. Байты одного адреса загружаются один раз даже для разных размеров декодирования.

Выход из аккаунта стирает и память, и папку фото; начатые загрузки отменяются и не наполняют кэш заново.

## 3. Правила хранения

`StoragePolicy` хранится в `UserDefaults` (`storage.keepMedia`, `storage.sizeLimit`) и применяется в `DeviceStorage.trim()`:

- **Хранить медиа**: 3 дня, 1 неделя, 1 месяц (по умолчанию), всегда. Удаляется то, к чему не обращались дольше срока.
- **Максимальный размер кэша**: 1 ГБ, 5 ГБ (по умолчанию), 20 ГБ, без ограничений. Сверх предела удаляется самое давно использованное.

Время обращения — дата изменения файла. Её обновляют: репозиторий медиа при каждом чтении из кэша, кэш картинок — один раз за запуск на файл (чтобы прокрутка не писала на диск).

Когда применяются: при запуске (в фоне), при уходе приложения в фон, после загрузки медиа (не чаще раза в минуту), сразу после смены правил.

«Прочее» не трогает то, что ещё нужно: файлы в `Caches/Outgoing` моложе суток (вложение может ещё отправляться) и временные файлы моложе часа (идёт запись кружка). Пустые папки вложений после удаления убираются.

## 4. Экран «Данные и память»

Настройки → «Данные и память» (между «Устройствами» и «Сообщениями»):

1. **Кольцо**: доли категорий в кэше, в центре размер кэша. Под ним «Maxly занимает N — X % памяти устройства» (кэш и база) и свободное место.
2. **Кэш**: непустые категории от большей к меньшей, у каждой цвет, доля и размер. Отметки: по умолчанию отмечено всё, снятая категория бледнеет на кольце.
3. **«Очистить N»** с подтверждением: стирает отмеченное. Фото стираются и из памяти, чтобы экран не показывал старые копии. Сообщения остаются, медиа снова скачаются при открытии.
4. **Хранить медиа** и **Максимальный размер кэша** — меню с вариантами, применяются сразу.
5. **База сообщений** — размер, без действия.

Пустой кэш — строка «Кэш пуст».

## 5. Устройство кода

| Слой | Что |
|---|---|
| Domain | `StorageCategory`, `KeepMediaPeriod`, `CacheSizeLimit`, `StoragePolicy`, `StorageUsage`, `StorageLayout`; протокол `StorageRepository`; `MediaType.videoNote` |
| Data | `DeviceStorage` (размеры, очистка, правила); `MediaRepositoryImpl` пишет по папкам категорий и зовёт `onStored` после загрузки; файл прежней раскладки при первом обращении переезжает в свою папку |
| UI | `ImageDiskCache` и `ImagePipeline` |
| Presentation | `StorageSettingsModel`, подписи категорий и вариантов |
| App | `DataStorageView` (Swift Charts `SectorMark`), сборка `DeviceStorage` в `AppContainer`, применение правил при уходе в фон |

Тесты: `DeviceStorageTests` (размеры, очистка, «Прочее», срок, предел, сохранение правил, папки категорий), `StorageSettingsModelTests`, кэш картинок в `OrbitleUITests`.
