# Мои истории

Архив своих историй: всё, что пользователь публиковал, в том числе истории, которые уже
исчезли из ленты.

## 1. Где

Настройки → секция с «Избранным»: строка «Мои истории» стоит сразу под «Избранным» и перед
«Контактами» и «Папками». Строка видна, только когда сервер включил архив:
`config.server["stories-history"]` → `AccountConfig.storiesHistory` → `AccountSettings.storiesHistory`.
Без флага строки нет.

## 2. Протокол

Запрос 219 через ядро: `ownStoryArchive(marker)` (ядро `ac9c7fb`).

- Первая страница — без курсора. Курсор передаётся, только если он непустой и не `"0"`.
- Сервер отдаёт до 30 историй и `marker` следующей страницы.
- Пустой `marker` (или `"0"`) в ответе — конец архива.

Мост отдаёт `IosStoryArchive(marker, stories)`; истории разбираются тем же кодом, что и лента
(`Story`, `StoryMedia`).

## 3. Экран

`StoryArchiveView` (`OrbitleApp/Screens/Stories`), модель `StoryArchiveModel`
(`OrbitlePresentation/Stories`).

- Сетка в три колонки, плитки 9:16: обложка (для видео — превью, для фото — сам снимок), дата
  и значок ▶︎ у видео.
- Последней строкой — индикатор: когда он появляется на экране, модель просит следующую
  страницу. Ошибка следующей страницы не стирает список: на месте индикатора кнопка
  «Повторить».
- Пустой архив — «Место для воспоминаний» и подпись «Здесь будут ваши истории, даже когда они
  исчезнут из ленты.».
- Ошибка первой страницы — экран ошибки с «Повторить».
- Потянуть вниз — загрузить архив заново с первой страницы.
- Нажатие на плитку открывает историю на весь экран: фото или видео со звуком, крестик
  закрывает. Отметок о просмотре архив не шлёт.
- Повторы историй между страницами отбрасываются по `id`.

## 4. Устройство кода

| Слой | Что |
|---|---|
| Domain | `StoryArchivePage(stories, marker)`, `isLast`; `StoriesRepository.archive(marker:)` (по умолчанию — `invalidRequest`) |
| Data | `MaxCore.ownStoryArchive(marker:)`; `CoreStoriesRepository.archive` (курсор `"0"` → без курсора, конец — пустой курсор) |
| Presentation | `StoryArchiveModel`: состояния `loading` / `empty` / `ready` / `failed`, `stories`, `canLoadMore`, `pageError`, `activate`, `reload`, `loadMore` |
| App | `MaxIosCore.ownStoryArchive` (учитывает лимит запросов), `AppContainer.storyArchiveModel()`, строка в `SettingsView`, `StoryArchiveView` |

## 5. Тесты

`StoryArchiveModelTests` (OrbitlePresentation, запускаются и на Linux):

- первая страница без курсора, дальше курсор ответа, пустой курсор — конец;
- пустой архив и курсор `"0"`;
- ошибка первой страницы и ошибка следующей.

## 6. Проверка на устройстве

1. Аккаунт с `stories-history`: строка «Мои истории» есть под «Избранным»; без флага — нет.
2. Архив больше 30 историй: прокрутка до конца подгружает следующую страницу.
3. Новый аккаунт без историй: «Место для воспоминаний».
4. Фото и видео открываются на весь экран.
